## MegaClient 1.10.0 Update Log

- Refreshed the built-in **MegaClient 0.14.2** client for **Minecraft 26.2**.

- Added a new **profile importer**, making it easier to move compatible Minecraft setups from **Lunar Client, CurseForge, Modrinth, Prism / MultiMC**, and normal Minecraft folders into MegaClient.

- Imported content can be added to a **new instance** or a compatible **existing instance**.

- Profile importing can bring across compatible **mods, configuration, resource packs, shaders, worlds, and common Minecraft settings**.

- Simplified the launcher design with fewer unnecessary animations and visual effects while keeping the interface clean and modern.

- Reduced background rendering and visual work to improve responsiveness and help keep more system resources available for Minecraft.

- Improved Game Performance Mode so the launcher becomes even quieter while Minecraft is running.

- Improved long content lists and general interface responsiveness.

- Added safer import handling so existing configuration is preserved and account or launcher login data is never copied.

- Included additional small performance, spacing, and interface clean-ups throughout the launcher.
