## MegaClient 1.9.6 Update Log

- Added a new automatic **game performance mode** for Fabric and other modded Minecraft instances.
- MegaClient now pauses launcher update downloads, update scans and server-status checks while Minecraft is running.
- Improved connection stability by preventing launcher background downloads from using bandwidth during gameplay.
- Reduced launcher CPU usage while playing by lowering only the launcher's own process priority.
- Improved performance with large or very chatty Fabric modpacks.
- Reduced launch-console resource usage and made it optional by default for new installations.
- Improved launch protection so background checks remain secure without repeatedly running expensive Windows scans.
- Improved protected-client verification with lighter log checking and less disk activity.
- Improved Fabric launches by reusing compatible loader versions instead of checking online before every start.
- Improved required Fabric API handling so it is not repeatedly resolved or downloaded on every launch.
- Improved server-status, loader-version and network caching.
- Reduced unnecessary Discord connection retries when Discord is closed.
- Included additional stability, cleanup and background-performance improvements.

The built-in MegaClient client remains **version 0.13.1** for **Minecraft 26.2**.
