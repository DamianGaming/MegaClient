## MegaClient 1.12.0 Update Log

- Completely refreshed the launcher with a new, cleaner design, simpler navigation, a redesigned home screen and a more focused Play experience.

- Reduced unnecessary animations and visual effects for a lighter, faster launcher while keeping smooth transitions where they matter.

- Fixed an issue that could prevent the built-in MegaClient client from launching correctly.

- Improved launch stability and background performance while Minecraft is running.

- Improved compatibility when importing Fabric instances that already have Fabric API installed, helping prevent duplicate mods and launch conflicts.

- Improved handling of outdated or incompatible required mods, with clearer errors.

- Reduced repeated mod scanning and other unnecessary background work.

- Kept the built-in **MegaClient 0.14.2** client for **Minecraft 26.2**, using the latest supplied build.
